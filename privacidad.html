NO PLACE TO REST · Política de privacidad

Última actualización: 27 de septiembre de 2026

Esta política se aplica al juego NO PLACE TO REST para Android (paquete com.noplacetorest.game), desarrollado por Ankaria Interactive.

Resumen

El juego no recoge, no guarda en servidores y no comparte ningún dato personal. No tiene anuncios, ni analíticas, ni cuentas de usuario, ni se conecta a internet.

Datos que se guardan en tu dispositivo

El juego guarda un único archivo local con tu progreso (capítulos y partidas) y tus opciones (volumen, vibración, dificultad, idioma). Ese archivo se queda en tu dispositivo, no se envía a nadie y no se incluye en las copias de seguridad en la nube. Si desinstalas el juego, se borra.

Permisos

Vibración: solo para la respuesta háptica durante el juego. Puedes desactivarla en las opciones. El juego no pide acceso a internet, ubicación, cámara, micrófono, contactos ni archivos.

Compras

El juego se compra a través de Google Play. Google gestiona el pago según su propia política de privacidad; el desarrollador no recibe tus datos de pago.

Edad

El juego contiene violencia extrema, sangre y lenguaje malsonante, y está dirigido solo a adultos (mayores de 18 años). No recoge datos de nadie, tampoco de menores.

Cambios en esta política

Si una versión futura cambiara lo que se describe aquí, esta página se actualizará antes de publicarla y cambiará la fecha de arriba.

Contacto

NO PLACE TO REST · Privacy Policy

Last updated: September 27, 2026

This policy applies to the Android game NO PLACE TO REST (package com.noplacetorest.game), developed by Ankaria Interactive.

Summary

The game does not collect, store on servers or share any personal data. It has no ads, no analytics, no user accounts, and it does not connect to the internet.

Data stored on your device

The game keeps a single local file with your progress (chapters and saves) and your settings (volume, vibration, difficulty, language). This file stays on your device, is never sent anywhere and is excluded from cloud backups. Uninstalling the game deletes it.

Permissions

Vibration: used only for haptic feedback during gameplay. It can be turned off in the settings. The game does not request internet, location, camera, microphone, contacts or file access.

Purchases

The game is purchased through Google Play. Google processes the payment under its own privacy policy; the developer does not receive your payment details.

Age

The game contains extreme violence, gore and strong language, and is intended for adults only (18+). It collects no data from anyone, including minors.

Changes to this policy

If a future version changes anything described here, this page will be updated before that version is released, along with the date above.
